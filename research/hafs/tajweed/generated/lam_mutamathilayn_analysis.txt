EXPLANATION
================================================================================

The discrepancy between mutamathilayn (2602) and shamsiyah (2579) is explained by:

1. SHARED ALLAH WORDS (2555):
   - Both lists share 2555 Allah (ٱللَّه) occurrences
   - Phonemizer labels ل→لّ as idgham_mutamathilayn (same letter merge)
   - Tajweed JSON labels it as lam_shamsiyah

2. SHARED NON-ALLAH (20):
   - Words like ٱللَّغۡوِ, ٱللَّعۡنَة, ٱللُّؤۡلُؤُ have ل+لّ
   - Both sources identify these patterns

3. ONLY IN MUTAMATHILAYN (+28):
   - و+و patterns: عَصَوا۟ وّ..., ٱتَّقَوا۟ وّ..., etc.
   - Cross-word ل→ل: قُل لّ..., بَل رّ...
   - These are true mutamathilayn but not lam_shamsiyah

4. ONLY IN SHAMSIYAH (+5):
   - ٱلۡتَقَى patterns (التقاء - the meeting)
   - Tajweed tags these as shamsiyah, phonemizer doesn't detect them

CONCLUSION:
- Phonemizer is correct in all cases it detects
- 5 ٱلۡتَقَى words are missing from phonemizer detection
- The difference is exactly the و+و and cross-word cases
