# Tafkheem Tarqeeq (Warsh Riwayah)

## Lam in لفظ الجلالة (Allah's Name) (Same as Hafs)

## General Lam Mutaharrikah (in regular words, not Allah) (Different from Hafs)

Lam Mutaharrikah is read with **tarqeeq (ترقيق)** always, but is read with **taghliz (تغليظ)** only when these conditions are met — this is in the Azraq tareeq only, in Warsh riwayah:

- The Lam has a fatha vowel.
- The Lam is preceded directly by one of the 3 letters: ط ظ ص. These letters can carry either a sukun or a fatha.

| Letter | Word | Ref |
| --- | --- | --- |
| ص (Sad) | اَ۬لصَّلَوٰةَ • فَصَلَ | 2:2 • 2:247 |
| ظ (Zha) | يُظْلَمُونَۖ | 2:280 |
| ط (Ta) | مَطْلَعِ | 97:5 |

### Exceptions

In these 2 cases, we can read with both **tarqeeq (ترقيق)** and **taghliz (تغليظ)**:

**Case 01:** There is an alif between the Lam and the letter preceding it (ط ظ ص). However, taghliz is preferred.

| Letter | Word | Ref |
| --- | --- | --- |
| ص (Sad) | فِصَالاً • يَّصَّٰلَحَا | 2:231 • 4:127 |
| ط (Ta) | طَالَ | 21:44 |

**Case 02:** When pausing on a Lam with fatha at the end of words, both readings are valid, however, **taghliz (تغليظ)** is preferred.

| Phrase | Ref |
| --- | --- |
| أَنْ يُّوصَلَ | 13:26 |
| فَلَمَّا فَصَلَ | 2:247 |

If the conditions for taghliz are met for a Lam in a word, and the cause of Imalah also occurs in the same word, the reason for Imalah takes precedence (muqaddam) over **taghliz (تغليظ)**, but only when the word occurs at the end of a verse.

| Phrase | Ref |
| --- | --- |
| وَلَا صَلّ۪ىٰۖ | 75:30 |

## Raa Mufakhkhamah & Muraqqaqah (راء مفخمة ومرققة)

Tafkheem raa is more common than Tarqeeq. Tarqeeq occurs only when one of the following conditions is present:

- Kasr (الكسر)
- Yaa (الياء)
- Imalah (الامالة)

> **Important:** These reasons have to be in the same word as the letter raa.

### Decision Tree

```
Raa
├── Kasra / Kasratan
│   └── Tarqeeq
│
├── Fatha / Fathatan / Damma / Dammatan / Sukun
│   │
│   ├── Preceded by Yaa Sakinah
│   │   (whether the Sukoon is written or implied)
│   │   └── Tarqeeq (Wasl and Waqf)
│   │
│   ├── Preceded by Kasra Lazim
│   │   (Kasra is part of the original word and not temporary)
│   │   │
│   │   ├── Directly preceded by Kasra Lazim
│   │   │   ├── Followed by Harf Isti'la' → Tafkheem
│   │   │   └── Not followed by Harf Isti'la' → Tarqeeq
│   │   │
│   │   └── Not directly preceded by Kasra Lazim
│   │       (one silent letter between Kasra and Raa)
│   │       ├── Silent letter = Qaf / Sad / Taa → Tafkheem
│   │       └── Silent letter ≠ Qaf / Sad / Taa → Tarqeeq
│   │
│   ├── Preceded directly by Kasra that is not Lazim
│   │   └── Tafkheem
│   │
│   └── Not preceded by Kasra
│       └── Tafkheem
│
├── Raa preceded by or coming after Alif Imalah
│   └── Tarqeeq (Wasl and Waqf)
│
└── General Rule
    └── Except in special cases, if the conditions for Tarqeeq are not satisfied → Tafkheem
```

## Special Cases

The Raa in the word **ذِكْرًاۖ** in the phrase **وَقَدْ آتَيْنَٰكَ مِن لَّدُنَّا ذِكْرًاۖ**:

| Length of اٰتَيْنَٰكَ with Badl (البدل) | Ruling for the Raa in ذِكْرًاۖ |
| --- | --- |
| 2 harakat | Tafkheem and Tarqeeq |
| 4 harakat | Tafkheem |
| 6 harakat | Tafkheem and Tarqeeq |
