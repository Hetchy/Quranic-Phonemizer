# Al-Madd (المد)

## Definition

- It is the prolongation of the sound when pronouncing the letter, and this occurs when it is followed by one of the three madd (elongation) letters, which are:
    - **The alif** -ا- preceded by a fatḥah
    - **The wāw** -و- preceded by a ḍammah
    - **The yā’** -ي- preceded by a kasrah

## Its Types

- **The madd is divided into two types:**
    - Madd Tabee‘i (مد طبيعي)
    - Madd far'ī (مد فرعي)

## Madd Tabee‘i (مد طبيعي)

- A normal madd is one where a madd letter is not followed by a **hamzah** or a **sukūn**. (same as Ḥafṣ)
- **Length:** 2 harakat

    | **Word** | **Ref** |
    | --- | --- |
    | اِ۬لْعَٰلَمِينَ | 1:1 |

### Appendices of Madd Tabee‘i (ملحقات المد الطبيعي)

- **Madd al-Iwad (مد العوض):**
    - It is the substitution of **tanwin** of **fathah** with an alif when waqf (pausing).
    - Pronounced as an alif instead of a tanwin.
    - **Length:** 2 harakat
    - **Technical Detection:** could be one of the following cases:
        - **U+0627 (ARABIC LETTER ALEF)** + **U+064B (ARABIC FATHATAN): اً**
        - **U+0627 (ARABIC LETTER ALEF)** + **U+0657 (ARABIC INVERTED DAMMA): اٗ**

        | **Word** | **Ref** |
        | --- | --- |
        | حَكِيماٗۖ | 33:1 |
        | عَلِيماٗۖ | 33:40 |
        | بَصِيراٗۖ | 35:46 |

- **Madd as-Silah as-Sughra (مد الصلة الصغرى):**
    - When the **hā' of the third-person absent pronoun** -هاء الضمير الغائب- occurs between two mutaḥarrik -متحركين- (vowelled) letters — no sukūn before or after.
    - The letter after it is not a hamzah.
    - Only pronounced in wasl (continuous recitation).
    - **Length:** 2 harakat

    | Phrase | Ref |
    | --- | --- |
    | نَزَّلَهُۥ عَلَىٰ | 2:96 |
    | اِنَّهُۥ هُوَ | 8:62 |
    | وَصَٰحِبَتِهِۦ وَبَنِيهِۖ | 80:36 |

- **The Muqatta'at:** the disjointed letters of the Qur'an, but only the letters combined in the sentence: **حي طهر**

    | Word | Ref |
    | --- | --- |
    | يَسِٓۖ | 36:1 |
    | ح۪مِٓۖ | 46:1 |
    | طَه۪ۖ | 20:1 |

## Madd far'ī (مد فرعي)

- It is one where a madd letter is followed by a **hamzah** or a **sukūn**.

### 1 - Madd Muttasil (مد متصل)

- It is where a madd letter is followed by a **hamzah**.
- **Length:** 6 harakat (in Hafs it is 4-5 harakat)

    | Word | Ref |
    | --- | --- |
    | اَ۬لسَّمَآءِ | 50:6 |
    | وَجِےٓءَ | 89:25 |
    | اُ۬لسُّوٓءَ | 16:94 |
    | جَآءَكُم | 60:1 |
    | وَابْتِغَآءَ | 60:1 |

- Obligatory extension.

### 2 - Madd Munfasil (مد منفصل)

- It is where a madd letter occurs at the end of the first word, followed by a hamzah in the next word.
- **Length:** 6 harakat (in Hafs it is 4-5 harakat)

    | Phrase | Ref |
    | --- | --- |
    | اِنَّآ أَنزَلْنَآ | 4:104 |
    | قَالُوٓاْ ءَامَنَّا | 5:43 |
    | أَنَآ أُحْيِۦ | 2:257 |
    | يَٰٓـَٔادَمُ | 7:18 |
    | يَٰٓأَيُّهَا | 7:158 |
    | هَٰٓؤُلَآءِ | 8:50 |
    | وَأَنَآ أَعْلَمُ | 60:1 |

#### Appendices of Madd Munfasil (ملحقات المد المنفصل)

##### a) Madd as-Silah al-Kubra (مد الصلة الكبرى)

- When the **hā' of the third-person absent pronoun** -هاء الضمير الغائب- occurs between two mutaḥarrik -متحركين- (vowelled/moving) letters.
- The letter after it is a hamzah.
- **Length:** 6 harakat

    | **Phrase** | **Ref** |
    | --- | --- |
    | لَهُۥٓ أَجْرُهُۥ | 2:111 |
    | مَالَهُۥٓ أَخْلَدَهُۥ | 104:3 |
    | هَٰذِهِۦٓ أَنْعَٰمٞ | 6:139 |

##### b) Madd Silat Mim al-Jam (مد صلة الجمع)

- Words ending with Mim al-Jam (plural) and after it there’s a hamzah.
- **Length:** 6 harakat
- **Technical Detection:** a combination of the following code points:

    | Unicode | Name |
    | --- | --- |
    | **U+0645** | ARABIC LETTER MEEM |
    | **U+064F** | ARABIC DAMMA |
    | **U+06E5** | ARABIC SMALL WAW |
    | **U+0653** | ARABIC MADDAH ABOVE |

- Examples:

    | **Phrase** | **Ref** |
    | --- | --- |
    | وَعَدُوَّكُمُۥٓ أَوْلِيَآءَۖ | 60:1 |
    | وَإِيَّاكُمُۥٓ أَن | 60:1 |
    | رَبِّكُمُۥٓۖ إِن | 60:1 |

### 3 - Madd al-Badal (مد البدل)

- When hamzah precedes the madd letter in a word.
- **Length:** can be 2-4-6 harakat (in Hafs it is just 2 harakat)
- In Algeria, 2 is prioritized. In Morocco, 4 is prioritized.

    | Word | Ref |
    | --- | --- |
    | ءَادَمَ | 2:30 |
    | ءَايَةٞۖ | 2:117 |
    | ءَامَنُواْۖ | 2:8 |
    | بَآءُو | 2:60 |
    | مُّتَّكِـِٕينَ | 18:31 |
    | اَ۬لْمَوْءُۥدَةُ | 81:8 |

#### Its Types

##### a) Badal Mohaqaq (بدل محقق)

- The hamzah is pronounced, and we can hear it.

    | Word | Ref |
    | --- | --- |
    | تَبَرَّءُواْ | 2:166 |
    | لِيُطْفِـُٔواْ | 61:8 |

##### b) Badal Mughayyar (بدل مغير)

- The hamzah is no longer pronounced, and we can't hear it.
- It has 3 types:
    - **Badal mughayyar bil-ibdal (بدل مغيّر بالإبدال):**
        - We change the hamzah into a madd letter with the same harakah as the letter preceding it.

        | Phrase | Ref | How it's read |
        | --- | --- | --- |
        | مِّنَ اَ۬لسَّمَآءِ اَ۟يَةٗ | 26:3 | مِّنَ اَ۬لسَّمَآءِ يايَةٗ |

    - **Badal mughayyar bin-naql (بدل مغيّر بالنقل):**
        - The transfer of the ḥarakah of the hamzah to the ṣaḥīḥ sākin letter preceding it, with the dropping of the hamzah from the pronunciation in waṣl.

        | Phrase | Ref | How it's read |
        | --- | --- | --- |
        | مَنَ اٰمَنَ  | 9:18 | مَنَامَنَ |

    - **Badal mughayyar bit-tashīl (بدل مغيّر بالتسهيل):**
        - By fully pronouncing the first hamzah and softening (tashīl) the second.

        | Word | Ref |
        | --- | --- |
        | ءَامَنتُم | 2:136 |

#### Exceptions of Madd al-Badal (مستثنيات مد البدل)

- **Length is only:** 2 harakat
- **Case 01:** If a hamzah is preceded by a sahih sakin letter.

    | Word | Ref |
    | --- | --- |
    | اَ۬لْقُرْءَانَ | 16:98 |
    | مَسْـُٔولاٗۖ | 25:16 |
    | اُ۬لظَّمْـَٔانُ | 24:38 |
    | مَذْءُوماٗ | 7:17 |

    - The word **اَ۬لْمَوْءُۥدَةُ** in 81:8 is an exception and it can be recited with 2-4-6 harakat.

- **Case 02:** words ending with a hamzah followed by fatḥah tanwin. This falls under Madd al-ʿIwaḍ at waqf.

    | Word | Ref |
    | --- | --- |
    | هُزُؤاٗۖ | 18:55 |

- **Case 03:** words starting with hamzat wasl.

    | Word | Ref |
    | --- | --- |
    | اُ۪يتُونِے | 10:79 |
    | اِ۟وتُمِنَ | 2:282 |
    | اَ۪يتِ | 10:15 |

- **Case 04:** the words

    | Word | Ref |
    | --- | --- |
    | إِسْرَآءِيلَ | 2:209 |
    | يُوَ۬اخِذُ | 16:61 |
    | عَاداٗ اَ۬لُّاول۪ىٰ | 53:49 |

    - The word إِسْرَآءِيلَ is read with 2 harakat waṣlan, but in waqf it's read with **Madd ‘Arid lil-Sukoon**.
    - The derivatives of the word يُوَ۬اخِذُ too.

#### Exception

- **The word ءَآلْـَٰٔنَ in Surat Yūnus can be read in multiple ways:**
    - It has 2 types of madd:
        - One in **the meeting of Hamzat al-Waṣl with the Hamzat al-Istifhām** (interrogative hamzah): **ءَالَٰنَ**
        - The madd after the Lām: **ءَالَٰنَ**
    - In continuous recitation (wasl):

| Madd of **ءَا** | Madd of **لَٰ** |
| --- | --- |
| **• Badal mughayyar bil-ibdal 2 harakat**<br>**• Badal mughayyar bil-ibdal 4 harakat**<br>**• Badal mughayyar bit-tashīl** | • 2 harakat<br>• 2 harakat<br>• 2 harakat |
| **• Badal mughayyar bil-ibdal 4 harakat**<br>**• Badal mughayyar bit-tashīl**<br>**• Badal mughayyar bil-ibdal 2 harakat** | • 2 - 4 harakat<br>• 2 - 4 harakat<br>• 2 harakat |
| **• Badal mughayyar bil-ibdal 4 harakat**<br>**• Badal mughayyar bit-tashīl**<br>**• Badal mughayyar bil-ibdal 2 harakat** | • 2 - 6 harakat<br>• 2 - 6 harakat<br>• 2 harakat |

- When stopping (waqf) on the word (ءَالْآنَ): the madd after the **lām** becomes **Madd al-'Aarid lis-Sukoon**.

### 4 - Madd ‘Arid lil-Sukoon (مد عارض للسكون)

- This occurs when a sukoon comes right after a madd letter, where that sukoon is "temporary/incidental", meaning it only appears because the reciter stops (pauses) at that word, not because the letter is naturally silent in continuous recitation.
- **P.S:** If the letter that ends up with sukoon is a **hamzah**, then it's **not** classified as Madd al-'Aarid lis-Sukoon — it falls under **Madd Muttasil**.
- **Length:** 2-4-6 harakat
- When choosing how many harakat to apply to **Madd al-'Aarid lis-Sukoon** (2, 4, or 6), the count chosen should be **greater than or equal to** the count used for **Madd al-Badal**.
    - If Madd al-Badal is recited with 2 counts → Madd al-'Aarid lis-Sukoon can be 2, 4, or 6.

| **Word** | **Ref** |
| --- | --- |
| اِ۬لْعَٰلَمِينَ | 1:1 |

### 5 - Madd Leen (مد لين)

- It has 2 types:

- **Madd al-Leen al-‘Arid lil-Sukoon (مد اللين العارض للسكون)**
    - It is the elongation of a **sākin wāw or yā’**, where the letter **before** it carries a **fatḥah**, **when stopping** (waqf) at that word.
    - **Length:** can be 2-4-6 harakat

    | Word | Ref |
    | --- | --- |
    | قُرَيْشٍ | 106:1 |
    | الصَّيْفِۖ | 106:2 |
    | اَ۬لْبَيْتِ | 106:3 |
    | خَوْفٍۖ | 106:5 |

- **Madd al-Leen al-Mahmouz (مد اللين المهموز)**
    - It occurs when a **hamzah** comes after the silent **yā’ or wāw**, where the letter before that yā’/wāw carries a fatḥah, within the same word, whether the hamzah is at the end of the word or in the middle of it.
    - It applies both at stop (waqf) and in continuous recitation (waṣl).
    - **Length:** 4-6 harakat

    | Word | Ref |
    | --- | --- |
    | كَهَيْـَٔةِ | 3:48 |
    | شَےْءٖ | 67:10 |

    - Exceptions:
        - The words **اَ۬لْمَوْءُۥدَةُ** and **مَوْئِلًا** can be recited with **only 2 harakat**.
        - Words derived from **سَوْءَٰتِ**, such as **سَوْءَٰتُهُمَا**, are another exception — they can be recited with **only 2 or 4 harakat**.

### 6 - Madd Lazim (مد لازم)

- It is when a sākin letter comes right after a madd letter, and this sukoon is fixed and original to the structure of the word, meaning it does not change whether in continuous recitation (waṣl) or stopping (waqf).
- **Length:** 6 harakat - same as hafs.
- It has 2 types:
    - Madd Lazim Kalimi and Madd Lazim Harfi
    - Each then splitting into: Muthaqqal and Mukhaffaf
        - **Madd Lazim Kalimi Muthaqqal**
        - **Madd Lazim Kalimi Mukhaffaf**
        - **Madd Lazim Harfi Muthaqqal**
        - **Madd Lazim Harfi Mukhaffaf**

- **1 - Madd Lazim Kalimi Muthaqqal:**
    - It is when a madd letter is followed by a letter that carries a **shaddah** in a word.

    | Word | Ref |
    | --- | --- |
    | اَ۬لْحَآقَّةُ | 69:1 |
    | اِ۬لطَّآمَّةُ | 79:34 |
    | اَ۬لضَّآلِّينَۖ | 1:7 |

- **2 - Madd Lazim Kalimi Mukhaffaf:**
    - It is when a madd letter is followed by a **sākin letter that is mukhaffaf, without shaddah**.

    | Word | Ref |
    | --- | --- |
    | مَحْي۪آےْ | 6:164 |
    | اَرَٰٓيْتَ | 107:1 |
    | ءَآنذَرْتَهُمُۥٓ | 2:5 |

- **Madd Lazim Harfi:**
    - It is when the madd occurs in a **letter**, not in a word, and it occurs at the **beginnings of surahs** (in the disjointed letters — *al-muqatta'ah*).
    - All the letters that take **Madd Lazim Harfi** are combined in the phrase: **نقص عسلكم**

- **3 - Madd Lazim Harfi Muthaqqal:**
    - It occurs specifically in a **muqatta'ah letter whose name is spelled with 3 letters**, where the letter **after the madd letter** carries a **shaddah**.

    | Word | Ref | How it is read |
    | --- | --- | --- |
    | أَلَٓمِّٓۖ | 2:1 | الف لام مّيم |
    | طَسِٓمِّٓۖ | 26:1 | طا سين مّيم |

- **4 - Madd Lazim Harfi Mukhaffaf:**
    - It is when the letter **after the madd letter** (within the muqatta'ah letter's spelling) is **sākin without shaddah**.

    | Word | Ref | How it is read |
    | --- | --- | --- |
    | أَلَٓمِّٓۖ | 2:1 | الف لام مّيم |
    | أَلَٓر۪ۖ | 10:1 | الف لام را |
    | قَٓۖ | 50:1 | قافْ |
    | صَٓۖ | 38:1 | صادْ |
